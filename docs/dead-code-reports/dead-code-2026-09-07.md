## Methodology notes

- **Analysis date:** 2026-09-07
- **Scope:** `src/js/*.js` (55 files) + `build.js` + `build-portable.js` + `build-config.js` + `smoke-tests.cjs`
- **`test/unit.cjs`:** File does not exist — excluded from scope
- **Build model:** The codebase uses a hybrid build. Nine files in `LEAF_MODULES`
  (declared in `build-config.js`) are true ES modules with `export` declarations.
  The remaining files are concatenated into `script.js` without ES module syntax;
  they share a flat global scope and are not cross-referenceable via import
  analysis alone.
- **Export analysis scope:** Only leaf modules can have meaningful dead-export
  findings. Concatenated files do not use `export`; their functions are global
  within the built bundle.
- **Dynamic imports:** None found (`import(...)` search returned 0 matches).
- **Default exports:** None declared in any leaf module.
- **Test harness:** `smoke-tests.cjs` accesses app internals through `window.__wl`
  (a runtime object populated by `07-lifecycle.js`), not via ES imports, so it
  does not create import-site references to leaf-module symbols.
- **Intra-file dead functions:** Checked all files in the `25-rollingsummary.js`,
  `20-migration.js`, `12c-gapreport.js`, `12d-weeklyreport.js`, and `15-notion.js`
  modules in detail. `callClaudeWithNotion` (`15-notion.js`) is exposed via
  `window._wlNotion` for use by a browser-side form — intentional, not dead.
  No other functions with ≥5-line bodies had zero call sites in any source file.

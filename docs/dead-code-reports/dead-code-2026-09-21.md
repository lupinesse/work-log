## Methodology notes

- **Analysis date:** 2026-09-21
- **Scope:** `src/js/*.js` (62 source files excluding `*.example.js`) + `build.js` +
  `build-portable.js` + `build-config.js` + `smoke-tests.cjs` +
  `test/unit/*.test.mjs` (37 test files). `test/unit.cjs` does not exist; tests
  live under `test/unit/*.test.mjs`.
- **No source changes since 2026-09-11:** `git log --since 2026-09-11 -- src/js/`
  returns only one commit (`c2f80a5`, a `lint-staged` dep bump). This sweep
  confirms the 2026-09-11 clean result holds without regression.
- **Leaf vs. concatenated module distinction.** 15 files are true ES modules
  listed in `LEAF_MODULES` (`build-config.js`): `app-constants.js`, `logger.js`,
  `date-labels.js`, `signifiers.js`, `12b-changelog-data.js`, `pure-fns.js`, and
  the nine `pure-fns-*.js` sub-modules. The remaining ~47 files have no
  `import`/`export` syntax — `build.js` concatenates them alphabetically into one
  flat global-scope script. Dead-export detection for leaf files therefore
  checks for bare identifier references in the concatenated scope, not just
  explicit `import { ... }` statements.
- **`pure-fns.js` barrel exclusion.** Every symbol in the nine `pure-fns-*.js`
  sub-modules is re-exported wholesale by `pure-fns.js`. References inside
  those `export { ... } from` blocks were excluded from the usage count — only
  call sites in non-barrel code were counted as real consumers. No symbol was
  found to be exclusively referenced via the barrel re-export with zero actual
  call sites.
- **No dynamic imports.** No `import(...)` calls exist anywhere in the
  codebase, so the static-analysis blind spot that dynamic imports normally
  introduce does not apply here.
- **Unused-local-function check.** A same-file-only check would produce
  numerous false positives because concatenated files share one global scope.
  Every candidate was verified via a whole-codebase grep for the bare
  identifier (not just `name(` call syntax), covering event-listener
  registrations and property assignments.
- No source files were modified — this report is informational only.

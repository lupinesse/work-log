## Methodology notes

- Analysis date: 2026-11-09
- Scope: `src/js/*.js` + `build.js` + `build-portable.js` + `build-config.js` +
  `smoke-tests.cjs` + `work-log.html` + `test/unit/*.mjs`
  (no `test/unit.cjs` exists; `test/unit/*.test.mjs` are the test files)
- All 33 `LEAF_MODULES` from `build-config.js` were checked. Non-leaf modules are
  concatenated into the bundle body and do not carry ES export declarations.
- Matching: whole-identifier regex against every file outside the declaring module;
  barrel re-exports (`pure-fns.js`) do not count as "use" — a symbol must be
  called somewhere in the concatenated scope or test suite to escape the dead list.
- The barrel-internal helpers (`buildTimesheetDescription`, `epicCutoffDate`,
  `collectRecentlyUsedCatIds`, `WEEKLY_REPORT_NO_TICKET_KEY`) are interesting cases:
  each is used only internally within its sub-module, re-exported by the barrel, but
  never called standalone. They are test-only because tests import them directly to
  verify the helper logic in isolation.

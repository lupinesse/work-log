## Methodology note — adapted for the concatenation model

The standard "named export never imported" analysis does not fit this codebase:
`src/js/*.js` are `sourceType: 'script'` modules concatenated into a single
browser IIFE at build time, so they do **not** use `import`/`export` — they call
each other through a shared global scope (only `logger.js` and `pure-fns*.js` are
true ES modules). ESLint cannot see those cross-file calls, which is why
`no-undef` and (since #242) `no-unused-vars`'s `vars:'local'` are disabled for
these files — and why genuinely-dead top-level symbols are invisible to lint.

This report therefore uses a reference-count signal instead: a top-level
`function` / `const` / `let` / `class` is **dead** when the whole-word symbol
appears exactly once (its own definition) across all of `src/js/`,
`work-log.html`, `build*.js`, `smoke-tests.cjs`, and `test/unit.mjs`.

## Methodology notes

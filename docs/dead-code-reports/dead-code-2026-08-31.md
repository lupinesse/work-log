### Notes on `renderChart()`

`renderChart()` is the highest-value cleanup item. It is called from four sites:

1. Three calls inside `04-render.js` itself.
2. One call inside `tickTimer()` in `03-timer.js` (runs every second while a timer is active).

Because `#chart` was removed from the DOM in the June 2026 architecture decision, every invocation exits on the first line. Removing the function and all four call sites will eliminate dead work on every timer tick.

## Methodology notes

- Analysis date: 2026-11-16
- Scope: `src/js/*.js` + `build.js` + `build-portable.js` + `test/unit/*.test.mjs` + `smoke-tests.cjs`
- **Build architecture:** `build-config.js` lists 34 *leaf modules* that are imported as ES modules at the top of `script.js`; every other `src/js/*.js` file is concatenated below the imports. Only leaf modules use `export`/`import` syntax; concatenated files rely on the flat module scope for all leaf-module symbols.
- **Export cross-reference method:** For each leaf-module export, the symbol name was searched (exact, case-sensitive) across all `src/js/` files, `test/unit/*.test.mjs`, `smoke-tests.cjs`, `build.js`, and `build-portable.js`. A symbol appearing only in its declaring file is flagged as dead or test-only.
- **Default exports:** None present — all leaf modules use named exports only.
- **Dynamic imports:** None found — no `import(…)` expressions exist.
- **Unused local functions:** Checked via pattern-matching for `function <name>` / `const <name> = ` declarations in leaf modules, then verified call-site presence within the same file.
- `src/js/00-config.local.example.js` is excluded from the build (`build.js` filters `*.example.js`) and was not treated as a consumption site.

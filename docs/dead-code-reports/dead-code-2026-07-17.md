## Methodology note — adapted for the concatenation model

This codebase does **not** fit the standard "named export never imported"
model that the dead-code procedure assumes. Only **six** `src/js/*.js` files
are true ES modules with `import`/`export` syntax:

- `src/js/logger.js`
- `src/js/pure-fns.js` (barrel — re-export statements only, declares no
  symbols of its own)
- `src/js/pure-fns-format.js`
- `src/js/pure-fns-validate.js`
- `src/js/pure-fns-tasks.js`
- `src/js/pure-fns-export.js`

The remaining **43** `src/js/*.js` files (`00-config.js` … `25-rollingsummary.js`,
including `00-config.local.example.js`, which contains no declarations and is
excluded from the build) contain **zero** `import`/`export` statements —
verified directly (`grep -L "^export\|^import" src/js/*.js` returns all 42
non-leaf, non-example files). `build.js` and `vite.config.js` concatenate them
alphabetically into a single ESM module (`script.js`), preceded by one
generated `import { … } from './src/js/pure-fns.js'` line and one
`import { wlLog } from './src/js/logger.js'` line. `build-portable.js` does
the same for the offline build, additionally stripping ESM syntax from the six
leaf modules and inlining everything into an IIFE. Inside that shared module
scope, the 43 script files call each other's top-level `function`/`const`/
`let`/`class` declarations directly by name — no `import` statement is used or
needed between them (confirmed by reading several files' cross-file call
sites, e.g. `initRapid` is declared in `16-rapid.js` and called bare from
`07-lifecycle.js:260`; `EMOJI_COMMON` is declared in `10a-tasks-render.js` and
used bare in `11-timeblock.js:142`).

Because of this architecture, literal per-file "import site" grepping (Step 3
of the standard procedure) is meaningless for the 43 script files, and a
literal same-file-only "is it called in this file" check (Step 4) produces
**50 false positives** — top-level functions with zero calls in their own
file that are, in fact, called from a different concatenated file (e.g.
`02-utils.js:fmtLabel`, `03-timer.js:resumeTimerIfActive`,
`08-pomodoro.js:checkNewDay`, `19-monthlylog.js:initMonthlyLog`, and 46
others). None of these are dead; they are simply cross-file calls that the
concatenation build resolves via shared scope rather than ESM imports.

This report therefore reuses the same adapted signal as every sweep since
2026-06-23:

- A top-level `function` / `const` / `let` / `class` declaration (in any of
  the 49 `src/js/*.js` files, leaf or non-leaf) is a **dead top-level symbol**
  when its whole-word text appears **zero times** outside its own declaration
  line, across the full analysis scope below.
- For the six true ES modules, named exports were additionally verified
  against `build-config.js`'s `readPureFnsExports()`, which reads
  `pure-fns.js`'s re-export statements and injects them as the
  `import { … } from './src/js/pure-fns.js';` line at the top of the
  concatenated `script.js` — this is how the 43 script files "consume"
  pure-fns/logger exports without any per-file `import` statement.
- Nested/local named function *expressions* (declared inside another
  function, therefore genuinely file-private — the concatenation architecture
  does not expose them to other files) were checked separately with a literal
  same-file, zero-calls-elsewhere test, restricted to bodies of ≥5 lines, per
  Step 4 of the procedure as written.

**Scope for whole-word reference counting:** all 49 `src/js/*.js` files,

  `import(` across all in-scope files, not assumed absent)
- Default exports: none exist in this codebase (verified by direct grep for
  `export default` across all in-scope files)
- Six files are true ES modules (`logger.js` + the five `pure-fns*.js`
  files); the other 43 `src/js/*.js` files use no `import`/`export` syntax
  and are concatenated into a single module scope by `build.js`/
  `build-portable.js`/`vite.config.js`, so "exported symbol" was interpreted
  as "any top-level declaration" for those 43 files, and cross-referenced
  against the whole concatenation scope (all 49 files) rather than per-file
  import sites, which do not exist for this architecture
- Generated build artefacts (`script.js`, `styles.css`, `dist/`, `portable/`,
  `docs/*.html`) are excluded from the scope — they are derived from source,
  not reference sites
- This is the eighth dead-code sweep on record (prior reports: 2026-05-30,

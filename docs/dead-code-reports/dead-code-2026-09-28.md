### Note on implementation-detail exports

`epicCutoffDate`, `collectRecentlyUsedCatIds`, `WEEKLY_REPORT_NO_TICKET_KEY`, and
`applyBackupRetention` are exported but their only direct usage outside the defining file is in
tests. In each case the export is justified:

- `epicCutoffDate` and `collectRecentlyUsedCatIds`: sub-steps of `findStaleCategories`, exported
  so they can be unit-tested in isolation (`pure-fns-epics.test.mjs`).
- `WEEKLY_REPORT_NO_TICKET_KEY`: a sentinel string, exported so tests can assert bucket identity
  without hard-coding the literal.
- `applyBackupRetention`: a reusable pure function that `buildBackupPayload` delegates to, exported
  so the retention logic can be tested independently.

None of these are dead: each is also re-exported by the `pure-fns.js` barrel and subsequently
imported into `script.js` by `build.js`.

## Methodology notes

- **Analysis date:** 2026-09-28
- **Scope:** `src/js/*.js` (63 files) + `build.js` + `build-portable.js` + `smoke-tests.cjs` +
  `test/unit/*.mjs` (37 files)
- **Build model:** LEAF_MODULES (`app-constants.js`, `logger.js`, `pure-fns-backup.js`,
  `pure-fns-epics.js`, `pure-fns-export.js`, `pure-fns-format.js`, `pure-fns-gapreport.js`,
  `pure-fns-rollingsummary.js`, `pure-fns-tasks.js`, `pure-fns-validate.js`,
  `pure-fns-weeklyreport.js`, `pure-fns.js`, `date-labels.js`, `12b-changelog-data.js`,
  `signifiers.js`) are imported as ES modules at the top of `script.js`; all other `src/js/*.js`
  files are concatenated into `script.js` in alphabetical order and share a flat module scope.
- **Dead-export rule:** A named export is dead if it has zero references in any src/js file other
  than its own defining file, in `build.js`, `build-portable.js`, `smoke-tests.cjs`, or
  `test/unit/*.mjs`.
- **Test-only rule:** An export is test-only if its only external references are in test files.
- **Dynamic imports:** Modules loaded via `` import(...) `` would be marked "possibly used".
  No such calls were found.
- **Local-function rule:** Functions defined but never called in the same file, with a body of ≥ 5
  lines, are reported as unused local functions. None were found.
- **`test/unit.cjs`:** Referenced in the task specification; this file does not exist in the
  repository. The 37 `test/unit/*.mjs` files were used as the equivalent test-file set.

## Architecture note

This project uses a **concatenated build** rather than ES module imports for
most app files. `build.js` alphabetically concatenates `src/js/*.js` (excluding
the six leaf modules listed in `build-config.js`) into a single `script.js`.
All non-leaf functions therefore live in a shared global scope; "dead code"
means *defined but never called*, not *exported but never imported*.

The six leaf modules (`logger.js`, `pure-fns.js`, and the four `pure-fns-*.js`
sub-modules) are proper ES modules imported at the top of `script.js`. Their
exports were cross-referenced against all import sites and found to be fully
consumed.

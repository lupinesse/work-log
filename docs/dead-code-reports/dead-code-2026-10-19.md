## Methodology notes

- Analysis date: 2026-10-19
- Scope: `src/js/*.js` + `build.js` + `build-portable.js` + `build-config.js` +
  `smoke-tests.cjs` + `work-log.html` + `test/unit/*.mjs`
- Build model: LEAF_MODULES (34 files) are imported as ES modules into `script.js`
  via generated `import { ... }` lines. Non-leaf modules are concatenated into the
  same bundle scope and call leaf exports by name without an import statement. A
  textual reference in any non-leaf module therefore counts as production use.
- Matching: whole-identifier regex against every file outside the defining module.
- No dynamic `import(...)` calls exist, so no exports can hide behind a string
  expression.

## Architecture note

This project uses **build concatenation**, not ES modules. All `src/js/*.js` files are
sorted alphabetically and wrapped in a single `(function() { … })()` IIFE by `build.js`.
There are no ES `import`/`export` statements in source files — every function declared at
file scope becomes a global within the IIFE closure.

"Dead exports" in this project means: **globally declared functions that are never called
from any source file, HTML handler, test, or build file**. The analysis covers:

- All 36 `src/js/*.js` files
- `build.js` and `build-portable.js`
- `smoke-tests.cjs` and `test/unit.cjs`
- `work-log.html` (for `onclick=` attributes)

`00-pure-fns.js` is the only file with a `module.exports` block (for Node/test access);
all symbols it exports are consumed in `test/unit.cjs` and are therefore **not dead**.

### Note 1 — `timerBarColor` (`src/js/03-timer.js:199`)

Computes an HSL colour interpolating green → red as elapsed time approaches the
`HYPERFOCUS_MINS` threshold. Was used by the old `#timerBar` element. The bar was
replaced by the Hero Card, whose colours are driven entirely by CSS state-modifier
classes (`hero-card--running`, `--paused`, etc.). The wrapper `updateTimerBarColor()`
(line 274) is now an explicit no-op stub (kept so `tickTimer` compiles without changes)
and no longer calls `timerBarColor`. The function itself is orphaned.

### Note 2 — `addCategory` (`src/js/02-utils.js:22`)

Opens a `prompt()` dialog, creates a new category, and updates `selectedTag`. The tag
management UI was redesigned: all add / rename / delete actions are now handled by
inline form controls rendered inside `renderTagRow()` (also in `02-utils.js`). No call
site for `addCategory` exists.

### Note 3 — `weekCount` (`src/js/02-utils.js:344`)

Counts log entries since the start of the current ISO week. The same logic is inlined
directly inside `render()` in `src/js/04-render.js` (the `statWeek` stat tile). No call
site for the standalone helper exists.

### Note 4 — `exportForDate` (`src/js/08-pomodoro.js:277`)

Builds and downloads a plaintext day-export combining the work-log summary with
Pomodoro session data. No call site exists anywhere; the export flow is handled
exclusively by `exportTxt()` in `src/js/05a-export.js`. This function also contains
`const seen = new Set()` at line 283 that is declared but never read within its body,
though this is moot while the function itself is unreachable.

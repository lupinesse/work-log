## Architecture note

The build system has two tiers:

- **Leaf modules** (listed in `LEAF_MODULES` in `build-config.js`): real ES modules imported via generated `import` statements at the top of `script.js`. Every named export from each leaf module is auto-detected by `readModuleExports()` and imported.
- **Concatenated files** (all other `src/js/*.js`): assembled verbatim into `script.js` and share one global scope. They have no ES module `export` statements, so they cannot have "dead exports" in the traditional sense.

Dead exports are therefore only possible from leaf modules.

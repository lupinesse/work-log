   `package.json` says `>=22.12.0`; runtime in this environment is `22.22.2`. The
   mismatch meant `npm run lint` and `npm run build` could not be verified locally.
   Update `engines.node` to `>=24.15.0` to match `.nvmrc`; ensure all CI and local
   environments install dependencies against the pinned version.

4. **Tag v1.9.1** — `v1.9.0` was tagged on 2026-06-12; at least 19 PRs (#227–#247) have
   been merged since, including ESLint cleanup (#242), dead-code sweeps (#243–#245),
   server-helper refactors (#239–#241), and QA documentation updates (#247). A patch tag
   captures the accumulated improvements and keeps the versioning cadence consistent.

5. **Split large modules** — `04-render.js` (646 non-blank lines),
   `09-clock-weather.js` (565), `11-timeflow.js` (536), `06a-hero.js` (512). All exceed
   comfortable single-responsibility thresholds. A thematic `04a-` sub-module extracting
   section-rendering helpers from `04-render.js` would be the smallest, highest-impact
   first split.

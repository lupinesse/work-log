## A note on how this report was delivered

`CLAUDE.md`'s Git Safety Protocol and this task's own instructions prohibit skipping
git hooks (`--no-verify`) without explicit user authorization, and this is an
unattended scheduled run with no user available to ask. Since the `commit-msg` hook is
unconditionally broken (Priority 1) and fixing it would mean editing `package.json` /
`package-lock.json` — out of scope for an audit-only task — this report could not be
committed through the repository's normal local path. No hook was bypassed and no
source file was touched to work around it; the finding is reported here, in full, as
the audit's top priority instead.

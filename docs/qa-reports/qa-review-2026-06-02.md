## Priorities for this week

1. **Fix the smoke-test crash at "Daily Log" (blocker)** — `smoke-tests.cjs` crashes with `TypeError: Cannot read properties of null (reading 'innerHTML')` immediately after "Daily Log" is printed. The uncommitted changes on this branch have removed or renamed a DOM element that a smoke test references by `#id` or class. Identify the element in the smoke-test "Daily Log" section and update the selector, or restore the element in the HTML. The branch cannot merge until `npm test` exits 0.

2. **Fix 10 new JSDoc `@type` description warnings in `06a-hero.js` and `16-rapid.js`** — JSDoc does not allow inline descriptions on `@type` tags inside `@typedef` blocks. Move descriptions to `@property` tags (one per field) or to a leading `@description` on the typedef. Affects lines 16–20 in `06a-hero.js` and lines 10–11, 22–23, 25–26, 90–91 in `16-rapid.js`. Fixes the regression in auto-generated docs.

3. **Fix 2 remaining JSDoc ERRORs in `18-dailylog.js`** — Lines 3 and 19: `entryId?: string` uses TypeScript optional-property syntax that the JSDoc parser rejects. Replace with `entryId: (string|undefined)`. Same fix needed for `parentEntryId?: string` on the same lines. Halves the ERROR count to 0 and ensures those return-type params appear correctly in generated HTML.

4. **Update `QA.md` with current test counts** — Still shows v1.8.4 figures (133 unit + 211 smoke = 344 total). Actual: **397 unit + ~285 smoke** (smoke count from `ok()` calls in `smoke-tests.cjs`). Add a v1.8.5–v1.8.9 acceptance delta section. This can be a standalone single-PR change.

5. **Correct stale line-count annotations in `ARCHITECTURE.md`** — `10-tasks.js` is documented as `929 lines` but the actual file is **142 lines** (post-split). `pure-fns.js` (824 lines, renamed from `00-pure-fns.js`) is still referenced by its old name `00-pure-fns.js` in two places. `11-timeblock.js` is annotated as 730 lines but is **1 050 lines** — the largest file in the codebase and a candidate for further splitting.

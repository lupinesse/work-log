# Work Log

ADHD-friendly work tracker — single HTML file, no dependencies, runs via localhost.

## Features
- Time logging with timer
- Today's tasks with status tracking (To do / In Progress / Done)
- Timeblock (08:00–18:00) with auto-blocks from log entries
- Pomodoro timer with session log
- Epics / category system
- Weather + rain forecast (Helsinki)
- Export to .txt
- Auto-carry of unfinished tasks to next day
- Completed tasks section (14-day rolling window)

## Running
Double-click `launch.bat` — opens at http://localhost:[port]/work-log.html

All data stored in browser localStorage.

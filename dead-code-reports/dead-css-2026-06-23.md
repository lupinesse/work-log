## Methodology

A class is a dead candidate when its literal name appears in **none** of
`work-log.html`, `src/js/`, `smoke-tests.cjs`, or `test/unit.mjs`. Because many
classes are built dynamically in JS (e.g. `` `bar-${cat}` ``), a candidate is
only treated as genuinely dead when its **stem is also absent from JS** — a
dynamic builder always leaves the stem (`bar-`, `dot-`, …) literally in the
source. Selectors nested under `&` (BEM modifiers) were not extracted, to avoid
false positives. Only `.class` selectors were analysed (ids are covered
separately and came back clean — even `#chart` retains a guarded
`getElementById('chart')` reference).

## Methodology notes
- Analysis date: 2026-06-23
- Scope: `src/css/*.scss` selectors cross-referenced against `work-log.html` +
  `src/js/` + `smoke-tests.cjs` + `test/unit.mjs`
- Dynamic detection: a candidate's stem (prefix up to the last `-`) is checked
  for literal presence in `src/js/`; if present, the class is treated as live.
- `&`-nested BEM modifiers were intentionally excluded from extraction.

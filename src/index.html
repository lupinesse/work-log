Welcome to Assistant

A private, no-backend chat interface for the OpenAI and Anthropic APIs:

  • Bring your own API key — usage-based pricing, no monthly subscription.
  • Switch between OpenAI (ChatGPT) and Anthropic (Claude) models any time.
  • Install it to your home screen or as a desktop app.
Choose a provider and paste an API key to begin.
Your API key is stored only in this browser's localStorage and is sent directly to the provider you choose — never to any other server.

Save conversation


Maximum number of previous messages sent to the API

The model has no memory between requests, so the conversation history is resent each time. Sending fewer messages saves tokens; sending more gives the model more context. Zero means only your latest message and the system prompt are sent.

System prompt

Instructions for the assistant that apply to every conversation. This is always sent, even when earlier messages are truncated.
